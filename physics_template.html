Recursive poem loop · experiment 2

Poem Loop Phase Diagram

The first run showed a loop that never stops moving yet keeps falling into the same dark style. Here we treat it as a noisy dynamical system: turn the noise (sampling temperature) up and down to look for a frozen phase, and drop very different starting poems in to see whether they share one attractor.

C. Strict zero temperature

    
The same start at T = 0, one request at a time with nothing else on the server, two chains. If the map is truly deterministic the two chains are identical, and a deterministic map on a finite set of texts must eventually freeze or cycle.

    

  


  

    
Method

    

      
Similarity
Python difflib ratio on the poem text: 1 means identical, about 0.2 is what two unrelated poems from this model share.

      
Second half
Rounds 30 to 60, after the early fast drift.

      
Attractor index
Word-count cosine to the average of run 1’s last 10 poems in every chain, minus cosine to the average of its first 5. Run 1 itself went from about −0.35 to +0.33. Above zero means the vocabulary is closer to where run 1 ended up. It is a word-level stand-in for “style”, since no embedding model was available.

      
Twins
Chains with the same start and temperature but a different seed. At T = 0 the seed has no effect, so any difference there comes from the server batching requests together.
